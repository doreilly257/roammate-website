# Pagefind Chunk Integrity Implementation Plan

> **For agentic workers:** REQUIRED: Use `subagent-driven-development` for implementation and independent review. Use numbered instructions, not checkbox tracking: `roammate-website-f6o` in Beads is the sole task tracker. Local implementation is authorized; proceed without another approval prompt. No deployment.

**Goal:** Make corrupted HTTP-200 Pagefind index/filter chunks produce the existing error/Retry UI rather than successful empty or incomplete results.

**Architecture:** Generate a deterministic exact-byte SHA256 manifest after Pagefind indexing. The existing search-page observer lazily validates this manifest and supplies native Fetch integrity, with isolated sticky-health epochs and explicit Retry cache recovery. Preserve the existing controller and public runtime destroy/import bounds.

**Tech Stack:** Astro, TypeScript, Node built-ins, Vitest, pinned Pagefind 1.5.2, native Fetch/Streams/SRI, real locally served Chrome.

**Authority:** `docs/superpowers/specs/2026-09-13-pagefind-integrity-design.md` is the complete contract. This plan implements it; it does not relax validation, privacy, compatibility, or acceptance requirements.
